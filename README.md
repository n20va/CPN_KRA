# Colored Petri Net Simulator

Приложение для построения и моделирования раскрашенных сетей Петри.

## О проекте

Проект представляет собой приложение для моделирования поведения раскрашенных сетей Петри.

Система разделена на несколько частей: доменную модель, движок симуляции, пользовательский интерфейс, консольный модуль и модуль тестов.

В проекте реализованы основные сущности сети Петри, логика определения доступных переходов и изменение маркировки сети при срабатывании переходов.

## Основные возможности

- описание мест и переходов;
- работа с маркировками;
- работа с мультимножествами токенов;
- определение доступных переходов;
- выполнение переходов;
- изменение состояния сети;
- пошаговая симуляция;
- автоматическое выполнение переходов;
- журнал событий симуляции;
- модульное тестирование основной логики.

## CpnLab.Domain

Модуль содержит основную предметную модель раскрашенной сети Петри.

Основные классы:

- `PetriNet` - модель сети Петри;
- `Marking` - текущее состояние сети;
- `Multiset` - мультимножество токенов;
- `Primitives` - базовые типы и идентификаторы элементов сети.

Модуль отвечает за представление структуры сети и данных, необходимых для симуляции.

## CpnLab.Engine

Модуль содержит логику выполнения сети.

Основные компоненты:

- `Simulator` - движок симуляции;
- `Events` - события, связанные с выполнением переходов.

Симулятор определяет, какие переходы доступны в текущем состоянии, выполняет их и изменяет маркировку сети.

## CpnLab.Ui2

Графический интерфейс для работы с сетью Петри.

Пользовательский интерфейс позволяет взаимодействовать с моделью сети и запускать симуляцию.

## CpnLab.Cli

Консольный модуль для запуска и проверки логики без графического интерфейса.

## CpnLab.Tests

Модуль содержит тесты для проверки работы симулятора.

В частности, тестируется:

- доступность переходов;
- корректность выполнения переходов;
- изменение маркировки;
- обработка различных состояний сети.

## Основные сущности

### PetriNet

Представляет структуру сети Петри и хранит информацию о местах, переходах и связях между ними.

### Marking

Хранит текущее распределение токенов по местам сети.

### Multiset

Используется для представления набора цветных токенов с учётом количества каждого значения.

### Simulator

Отвечает за выполнение модели.

Основные задачи симулятора:

- анализ текущей маркировки;
- определение доступных переходов;
- выполнение выбранного перехода;
- обновление состояния сети;
- фиксация событий выполнения.

## Принцип работы

Состояние сети определяется текущей маркировкой.

Перед выполнением перехода симулятор проверяет, достаточно ли входных токенов для его срабатывания.

Если переход доступен, необходимые токены удаляются из входных мест, после чего новые токены добавляются в выходные места.

```text
Current Marking
      |
      v
Check Enabled Transitions
      |
      v
Select Transition
      |
      v
Consume Input Tokens
      |
      v
Produce Output Tokens
      |
      v
New Marking
```

## Тестирование

В проекте выделен отдельный модуль `CpnLab.Tests`.

Тесты проверяют основную логику симуляции и помогают убедиться, что изменение состояния сети выполняется корректно.

Для запуска тестов:

```bash
dotnet test
```

## Запуск

Для работы с проектом необходим установленный .NET SDK.

Клонирование репозитория:

```bash
git clone https://github.com/n20va/CPN_KRA.git
cd CPN_KRA
```

Восстановление зависимостей:

```bash
dotnet restore
```

Сборка проекта:

```bash
dotnet build
```

Запуск тестов:

```bash
dotnet test
```

Для запуска графического приложения можно выбрать проект `CpnLab.Ui2` в IDE и запустить его как основной проект.
